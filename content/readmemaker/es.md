# Readme Maker

**Readme Maker** es una aplicación web moderna que te permite crear archivos README profesionales para tus proyectos en GitHub. Gracias a su interfaz de arrastrar y soltar, plantillas personalizables y vista previa en tiempo real, facilita y acelera el proceso de creación de README.

## Acerca del Proyecto

Readme Maker es una herramienta amigable diseñada para ayudar a los desarrolladores a presentar sus proyectos de la mejor manera posible. Características:

- **Plantillas Personalizables**: Plantillas predefinidas para distintos tipos de proyectos  
- **Vista Previa en Tiempo Real**: Visualiza los cambios al instante  
- **Diseño Responsive**: Funciona perfectamente en todos los dispositivos  
- **Soporte Multilingüe**: Opciones de idioma en TR/EN  
- **Soporte de Tema**: Modos claro y oscuro disponibles

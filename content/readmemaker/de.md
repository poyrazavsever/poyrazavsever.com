# Readme Maker

**Readme Maker** ist eine moderne Webanwendung zur Erstellung professioneller README-Dateien für deine GitHub-Projekte. Mit der Drag-and-Drop-Oberfläche, anpassbaren Vorlagen und der Live-Vorschau vereinfacht und beschleunigt sie den Erstellungsprozess erheblich.

## Über das Projekt

Readme Maker ist ein benutzerfreundliches Tool, das Entwicklern hilft, ihre Projekte optimal zu präsentieren. Funktionen:

- **Anpassbare Vorlagen**: Vorgefertigte Templates für verschiedene Projekttypen  
- **Live-Vorschau**: Änderungen in Echtzeit anzeigen  
- **Responsives Design**: Funktioniert auf allen Geräten reibungslos  
- **Mehrsprachige Unterstützung**: Sprachoptionen auf TR/EN  
- **Themenunterstützung**: Hell-/Dunkelmodus verfügbar

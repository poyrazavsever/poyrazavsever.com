# Readme Maker

**Readme Maker**, GitHub projeleriniz için profesyonel README dosyaları oluşturmanızı sağlayan modern bir web uygulamasıdır. Sürükle-bırak arayüzü, özelleştirilebilir şablonları ve anlık önizleme özelliği ile README oluşturma sürecinizi kolaylaştırır ve hızlandırır.

## Hakkında

Readme Maker, geliştiricilerin projelerini en iyi şekilde tanıtabilmeleri için tasarlanmış kullanıcı dostu bir araçtır. Özellikler:

- **Özelleştirilebilir Şablonlar**: Farklı proje türleri için hazır şablonlar
- **Anlık Önizleme**: Yaptığınız değişiklikleri anında görüntüleme
- **Responsive Tasarım**: Tüm cihazlarda kusursuz çalışma
- **Çoklu Dil Desteği**: TR/EN dil seçenekleri
- **Tema Desteği**: Açık/Koyu tema seçenekleri

**Önizleme**

**Dışa Aktarma**

## Kurulum ve Kullanım

```bash
# Projeyi klonlayın
git clone https://github.com/poyrazavsever/readme-maker.git

# Proje dizinine gidin
cd readme-maker

# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev
```

# Athena Wellness

**Athena Wellness** is a fullstack web application developed for a client providing healthcare consulting services. It offers blog content and consulting features through a modern user interface.

## About

Athena Wellness is a professional web platform offering healthcare consultancy and informative services:

- **Blog Management**: System for creating and editing content  
- **Consulting Services**: Online appointment and tracking  
- **Dynamic Content**: Easily updatable page structures  
- **Admin Panel**: Advanced content control system  
- **SEO Optimization**: Search-engine-friendly setup

## Installation & Usage

``` bash
git clone https://github.com/poyrazavsever/athena.git
cd athena
npm install
npm run firebase:init
npm run dev
```

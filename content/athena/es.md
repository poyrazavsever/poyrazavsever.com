# Athena Salud

**Athena Salud** es una aplicación web fullstack desarrollada para un cliente que brinda servicios de asesoramiento en salud. Ofrece contenidos de blog y servicios de consulta en una interfaz moderna.

## Acerca del Proyecto

Athena Salud es una plataforma profesional en línea para ofrecer orientación y educación en temas de salud:

- **Gestión de Blog**: Sistema para crear y editar publicaciones  
- **Servicios de Consulta**: Sistema de citas y seguimiento en línea  
- **Contenido Dinámico**: Estructura de página fácilmente actualizable  
- **Panel de Administración**: Control de contenidos avanzado  
- **Optimización SEO**: Estructura amigable con motores de búsqueda

## Instalación y Uso

``` bash
git clone https://github.com/poyrazavsever/athena.git
cd athena
npm install
npm run firebase:init
npm run dev
```

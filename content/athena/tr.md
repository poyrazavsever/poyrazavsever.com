# Athena Şifa

**Athena Şifa**, sağlık danışmanlığı hizmetleri sunan bir müşterim için geliştirdiğim fullstack web uygulamasıdır. İçerik yönetimi, blog yazıları ve danışmanlık hizmetlerini modern bir arayüzle sunar.

## Hakkında

Athena Şifa, sağlık danışmanlığı ve bilgilendirme hizmetleri sunan profesyonel bir web platformudur:

- **Blog Yönetimi**: İçerik oluşturma ve düzenleme sistemi
- **Danışmanlık Hizmetleri**: Online randevu ve takip sistemi
- **Dinamik İçerik**: Kolay güncellenebilir sayfa yapısı
- **Yönetim Paneli**: Kapsamlı içerik kontrol sistemi
- **SEO Optimizasyonu**: Arama motoru dostu yapı

## Kurulum ve Kullanım

```bash
# Projeyi klonlayın
git clone https://github.com/poyrazavsever/athena.git

# Proje dizinine gidin
cd athena

# Bağımlılıkları yükleyin
npm install

# Firebase ayarlarını yapılandırın
npm run firebase:init

# Geliştirme sunucusunu başlatın
npm run dev
```

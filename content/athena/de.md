# Athena Gesundheit

**Athena Gesundheit** ist eine Fullstack-Webanwendung, die für einen Kunden im Bereich Gesundheitsberatung entwickelt wurde. Sie bietet Bloginhalte und Beratungsdienste über eine moderne Benutzeroberfläche.

## Über das Projekt

Athena Gesundheit ist eine professionelle Webplattform für Gesundheitsberatung und Informationsdienste:

- **Blogverwaltung**: Erstellung und Bearbeitung von Inhalten  
- **Beratungsdienste**: Online-Terminvereinbarung und Nachverfolgung  
- **Dynamische Inhalte**: Einfach aktualisierbare Seitenstrukturen  
- **Admin-Panel**: Umfangreiche Inhaltskontrolle  
- **SEO-Optimierung**: Suchmaschinenfreundliches Setup

## Installation & Nutzung

``` bash
git clone https://github.com/poyrazavsever/athena.git
cd athena
npm install
npm run firebase:init
npm run dev
```

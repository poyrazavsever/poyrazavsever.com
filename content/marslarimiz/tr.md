# Marşlarımızın Anlamı

**Marşlarımızın Anlamı**, Türkiye Cumhuriyeti'ne ait marşların paylaşıldığı, hikayelerinin anlatıldığı ve kelime anlamlarının yapay zeka desteğiyle incelenebildiği modern bir web platformudur. Kültürel mirasımızın önemli parçaları olan marşlarımızı daha iyi anlamamızı ve gelecek nesillere aktarmamızı sağlar.

## Hakkında

Marşlarımızın Anlamı, milli marşlarımızı dijital ortamda yaşatmak ve anlamlarını kolayca öğrenmek için tasarlanmış kullanıcı dostu bir platformdur:

- **Marş Kütüphanesi**: Geniş marş arşivi ve detaylı bilgiler
- **Yapay Zeka Desteği**: Kelimelerin anlamlarını otomatik açıklama
- **Hikaye Paylaşımı**: Marşların tarihsel hikayelerini paylaşma
- **Sosyal Etkileşim**: Yorum ve tartışma imkanı
- **Tema Desteği**: Açık/Koyu tema seçenekleri
- **Responsive Tasarım**: Tüm cihazlarda kusursuz deneyim

2. **Yapay Zeka Analizi**

3. **Sosyal Özellikler (Yakında)**

## Kurulum ve Kullanım

```bash
# Projeyi klonlayın
git clone https://github.com/poyrazavsever/marslarinanlami.git

# Proje dizinine gidin
cd marslarinanlami

# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# ya da --> marslarinanlami.vercel.app
```

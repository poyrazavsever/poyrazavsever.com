# The Meaning of Our Anthems

**The Meaning of Our Anthems** is a modern web platform where national anthems of the Republic of Turkey are shared, their stories explained, and word meanings analyzed with AI support. It helps us better understand our cultural heritage and pass it down to future generations.

## About

The Meaning of Our Anthems is a user-friendly platform designed to keep our national anthems alive in digital form and make their meanings easily accessible:

- **Anthem Library**: Extensive anthem archive with detailed information  
- **AI Support**: Automatic explanations of word meanings  
- **Storytelling**: Sharing historical stories behind the anthems  
- **Social Interaction**: Comments and discussion features  
- **Theme Support**: Light/Dark mode options  
- **Responsive Design**: Seamless experience across all devices

## Installation and Usage

``` bash
# Clone the project
git clone https://github.com/poyrazavsever/marslarinanlami.git

# Enter the project directory
cd marslarinanlami

# Install dependencies
npm install

# Start the development server
npm run dev

# or visit --> marslarinanlami.vercel.app
```

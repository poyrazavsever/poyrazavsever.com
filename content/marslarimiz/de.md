# Die Bedeutung unserer Märsche

**Die Bedeutung unserer Märsche** ist eine moderne Webplattform, auf der die Nationalhymnen der Republik Türkei geteilt, ihre Geschichten erklärt und Wortbedeutungen mit KI-Unterstützung analysiert werden. Sie hilft uns, unser kulturelles Erbe besser zu verstehen und an zukünftige Generationen weiterzugeben.

## Über die Plattform

Die Bedeutung unserer Märsche ist eine benutzerfreundliche Plattform, die darauf ausgelegt ist, unsere Nationalhymnen digital zu erhalten und ihre Bedeutung leicht zugänglich zu machen:

- **Marsch-Bibliothek**: Umfangreiches Archiv mit detaillierten Informationen  
- **KI-Unterstützung**: Automatische Erklärung von Wortbedeutungen  
- **Erzählungen**: Historische Geschichten hinter den Märschen teilen  
- **Soziale Interaktion**: Kommentar- und Diskussionsfunktionen  
- **Themenunterstützung**: Hell-/Dunkelmodus-Optionen  
- **Responsives Design**: Nahtlose Nutzung auf allen Geräten

## Funktionen

**Marschkatalog**  
   - Kategorisierte Marschliste  
   - Liedtexte  
   - Historische Informationen

**KI-Analyse**  
   - Erklärung von Wortbedeutungen  
   - Erläuterung kultureller Bezüge

**Soziale Funktionen (Demnächst)**  
   - Benutzerprofile  
   - Kommentarsystem  
   - Marschfreigabe

**Lernwerkzeug**

## Installation und Nutzung

``` bash
# Projekt klonen
git clone https://github.com/poyrazavsever/marslarinanlami.git

# In das Projektverzeichnis wechseln
cd marslarinanlami

# Abhängigkeiten installieren
npm install

# Entwicklungsserver starten
npm run dev

# oder besuchen --> marslarinanlami.vercel.app
```

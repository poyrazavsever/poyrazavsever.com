# El significado de nuestros himnos

**El significado de nuestros himnos** es una plataforma web moderna donde se comparten los himnos nacionales de la República de Turquía, se cuentan sus historias y se analizan las palabras con soporte de IA. Nos ayuda a comprender mejor nuestro patrimonio cultural y transmitirlo a las futuras generaciones.

## Acerca de

El significado de nuestros himnos es una plataforma fácil de usar diseñada para mantener vivos nuestros himnos nacionales en formato digital y hacer que sus significados sean fácilmente accesibles:

- **Biblioteca de himnos**: Archivo amplio con información detallada  
- **Soporte IA**: Explicación automática de significados de palabras  
- **Narración**: Compartir historias históricas detrás de los himnos  
- **Interacción social**: Funciones de comentarios y discusión  
- **Temas disponibles**: Opciones modo claro/oscuro  
- **Diseño responsive**: Experiencia fluida en todos los dispositivos

## Instalación y Uso

``` bash
# Clonar el proyecto
git clone https://github.com/poyrazavsever/marslarinanlami.git

# Entrar en el directorio del proyecto
cd marslarinanlami

# Instalar dependencias
npm install

# Iniciar el servidor de desarrollo
npm run dev

# o visita --> marslarinanlami.vercel.app
```

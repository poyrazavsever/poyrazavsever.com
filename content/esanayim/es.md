# Diseño UI de E-sanayim

## Sobre el Proyecto

**E-sanayim** es un diseño de interfaz de usuario (UI) creado para nuestro proyecto emprendedor que fue finalista en el evento **Pitching Day** organizado por la Universidad Técnica de Ostim. El objetivo principal del proyecto es ofrecer una plataforma que facilite la transformación digital de las empresas industriales.

Esta plataforma permite a las empresas construir una identidad digital, mostrar sus productos y servicios, y digitalizarse según las necesidades del sector.

## Proceso de Diseño

Durante el proceso de diseño UI se priorizaron los siguientes principios:

- **Interfaz amigable:** Experiencia de usuario simple, clara e intuitiva.
- **Compatibilidad móvil:** Todos los diseños fueron creados con enfoque responsive.
- **Estética profesional:** Paleta de colores, tipografía y jerarquía visual adaptadas al sector industrial.
- **Estructura basada en componentes:** Principio modular con componentes reutilizables.

## Páginas Diseñadas

- Página principal
- Página de perfil de empresa
- Página de productos y servicios
- Formulario de contacto / postulación
- Panel de administración (a nivel wireframe)

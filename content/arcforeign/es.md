# ARC Foreign Trade

**ARC Foreign Trade** es el proyecto de sitio web moderno que renové durante mis prácticas para una empresa de comercio exterior. Fue diseñado para reflejar de manera profesional los productos, servicios e identidad corporativa de la empresa.

## Acerca del Proyecto

ARC Foreign Trade es una plataforma web profesional en comercio internacional y exportación:

- **Catálogo de Productos**: Sistema detallado de gestión de productos  
- **Sistema de Contacto**: Formulario automatizado y sistema de notificaciones  
- **Diseño Moderno**: Interfaz amigable para el usuario  
- **Optimización SEO**: Estructura amigable para los motores de búsqueda

## Funcionalidades

**Blog**
   - Publicar entradas de blog  
   - Editar, eliminar y archivar publicaciones  
   - Búsqueda de blog y estadísticas  

**Gestión de Productos**
   - Listado por categorías  
   - Páginas detalladas de productos  
   - Sistema de filtros  

**Sistema de Contacto**
   - Formulario de contacto  
   - Notificaciones automáticas por correo  

**Optimización**
   - Carga rápida de páginas  
   - Diseño responsive  
   - Estructura compatible con SEO  
   - Optimización de imágenes  

## Instalación y Uso

```bash
# Clonar el proyecto
git clone https://github.com/poyrazavsever/arc_foreign_trade.git

# Entrar al directorio del proyecto
cd arc_foreign_trade

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

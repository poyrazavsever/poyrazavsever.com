# ARC Foreign Trade

**ARC Foreign Trade** ist das moderne Website-Projekt, das ich während meines Praktikums für ein Außenhandelsunternehmen überarbeitet habe. Es wurde entwickelt, um die Produkte, Dienstleistungen und das Corporate Design professionell zu präsentieren.

## Über das Projekt

ARC Foreign Trade ist eine professionelle Webplattform im Bereich internationaler Handel und Export:

- **Produktkatalog**: Detailliertes Produktverwaltungssystem  
- **Kontaktsystem**: Automatisiertes Formular- und Benachrichtigungssystem  
- **Modernes Design**: Benutzerfreundliche Oberfläche  
- **SEO‑Optimierung**: Suchmaschinenfreundliche Struktur

## Installation & Nutzung

```bash
# Projekt klonen
git clone https://github.com/poyrazavsever/arc_foreign_trade.git

# In das Projektverzeichnis wechseln
cd arc_foreign_trade

# Abhängigkeiten installieren
npm install

# Entwicklungsserver starten
npm run dev
```

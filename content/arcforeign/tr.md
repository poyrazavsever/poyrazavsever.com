# ARC Foreign Trade

**ARC Foreign Trade**, staj yaptığım süre boyunca yenilediğim, dış ticaret şirketisinin modern web sitesi projesidir. Şirketin ürünlerini, hizmetlerini ve kurumsal kimliğini profesyonel bir şekilde yansıtmak için tasarlanmıştır.

## Hakkında

ARC Foreign Trade, uluslararası ticaret ve ihracat alanında hizmet veren profesyonel bir web platformudur:

- **Ürün Kataloğu**: Detaylı ürün yönetim sistemi
- **İletişim Sistemi**: Otomatik form ve bildirim sistemi
- **Modern Tasarım**: Kullanıcı dostu arayüz
- **SEO Optimizasyonu**: Arama motoru dostu yapı

## Kurulum ve Kullanım

```bash
# Projeyi klonlayın
git clone https://github.com/poyrazavsever/arc_foreign_trade.git

# Proje dizinine gidin
cd arc_foreign_trade

# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev
```

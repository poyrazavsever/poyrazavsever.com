# Conciencia Sísmica

**Conciencia Sísmica** es una plataforma educativa interactiva que ofrece capacitaciones y pruebas personalizadas para estudiantes, docentes, niños y padres sobre qué hacer antes, durante y después de un terremoto.

## Acerca del Proyecto

Conciencia Sísmica es una plataforma web educativa cuyo objetivo es concientizar a todos los sectores de la sociedad sobre los terremotos:

- **Capacitaciones categorizadas**: Contenidos personalizados según edad y rol  
- **Pruebas interactivas**: Evaluaciones para medir el aprendizaje  
- **Contenidos informativos**: Información validada por expertos  
- **Guía de emergencia**: Acceso rápido a datos vitales  
- **Diseño accesible**: Interfaz apta para todas las edades

## Funcionalidades

**Módulos Educativos**
   - Contenido por grupo de edad  
   - Materiales interactivos  

**Pruebas y Evaluación**
   - Ejercicios prácticos  
   - Retroalimentación inmediata  
   - Estadísticas de rendimiento  

**Herramientas de Emergencia**
   - Guía de acceso rápido  
   - Mapa de zonas de reunión  
   - Lista de control ante emergencias  
   - Números de contacto importantes  

## Instalación y Uso

``` bash
git clone https://github.com/HSD-OSTIMTECH/DepremBilinci.git
cd DepremBilinci
npm install
npm run dev
```

## Proceso de Desarrollo

**Investigación y Contenido (1 semana)**
   - Entrevistas con expertos  
   - Recolección de información  
   - Preparación del currículo  

**Diseño y Desarrollo (1 semana)**
   - Diseño UI/UX  
   - Desarrollo del frontend  
   - Integración backend  

**Pruebas y Mejora (1 semana)**
   - Pruebas de usuario  
   - Validación de contenido  
   - Optimización del rendimiento

# Deprem Bilinci

**Deprem Bilinci**, deprem öncesi, sırası ve sonrasında yapılması gerekenler hakkında öğrenci, öğretmen, çocuk ve ebeveyn kategorilerine özel eğitimler ve testler barındıran interaktif bir eğitim platformudur.

## Hakkında

Deprem Bilinci, toplumun her kesiminin deprem konusunda bilinçlenmesini hedefleyen eğitsel bir web platformudur:

- **Kategorize Eğitimler**: Yaş ve rol bazlı özelleştirilmiş içerikler
- **İnteraktif Testler**: Öğrenme düzeyini ölçen değerlendirmeler
- **Bilgilendirici İçerikler**: Uzman onaylı deprem bilgileri
- **Acil Durum Rehberi**: Hızlı erişilebilir hayati bilgiler
- **Erişilebilir Tasarım**: Her yaş grubuna uygun arayüz

## Özellikler

**Eğitim Modülleri**
   - Yaş gruplarına özel içerikler
   - Etkileşimli öğrenme materyalleri

**Test ve Değerlendirme**
   - Pratik uygulamalar
   - Anlık geri bildirim
   - Başarı istatistikleri

**Acil Durum Özellikleri**
   - Hızlı erişim rehberi
   - Toplanma alanları haritası
   - Acil durum kontrol listesi
   - Önemli telefon numaraları

## Kurulum ve Kullanım

```bash
# Projeyi klonlayın
git clone https://github.com/HSD-OSTIMTECH/DepremBilinci.git

# Proje dizinine gidin
cd DepremBilinci

# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev
```

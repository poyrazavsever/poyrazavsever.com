# Erdbebenbewusstsein

**Erdbebenbewusstsein** ist eine interaktive Bildungsplattform, die spezielle Schulungen und Tests für Schüler, Lehrer, Kinder und Eltern bietet – zu Maßnahmen vor, während und nach einem Erdbeben.

## Über das Projekt

Erdbebenbewusstsein ist eine Bildungsplattform, die sich zum Ziel gesetzt hat, das Bewusstsein in allen Gesellschaftsschichten zu stärken:

- **Kategorisierte Schulungen**: Inhalte nach Alter und Rolle angepasst  
- **Interaktive Tests**: Wissenserfassung durch Quizformate  
- **Informative Inhalte**: Expertengeprüftes Wissen  
- **Notfallführer**: Lebenswichtige Informationen auf Abruf  
- **Barrierefreies Design**: Benutzerfreundlichkeit für jedes Alter

## Funktionen

**Lernmodule**
   - Altersgerechte Inhalte  
   - Interaktive Lernmaterialien  

**Tests & Bewertung**
   - Praktische Übungen  
   - Sofortige Rückmeldung  
   - Erfolgsstatistiken  

**Notfall-Funktionen**
   - Schneller Notfall-Zugriff  
   - Karte mit Sammelplätzen  
   - Notfall-Checklisten  
   - Wichtige Rufnummern  

## Installation & Nutzung

``` bash
git clone https://github.com/HSD-OSTIMTECH/DepremBilinci.git
cd DepremBilinci
npm install
npm run dev
```

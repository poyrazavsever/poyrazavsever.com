# Pati Tekno

**Pati Tekno** es una plataforma innovadora que ofrece soluciones digitales creativas desarrolladas con tecnologías web modernas. Se destaca tanto por su interfaz amigable como por su potente infraestructura. Sirve como ejemplo en el desarrollo web utilizando herramientas de código abierto, escalables y modernas en sus proyectos.

## Acerca de

El objetivo de Pati Tekno es proporcionar a los usuarios un acceso rápido a la información, presentar contenido con un enfoque de diseño moderno y crear un ecosistema digital sostenible y desarrollable gracias a su infraestructura técnica. Gracias a esta estructura que equilibra bien el diseño y el software, la experiencia del usuario es una prioridad.

## Tecnologías Utilizadas

Las siguientes tecnologías se utilizan activamente en la construcción del proyecto **Pati Tekno**:

### Frontend

| Tecnología | Descripción | Icono |
|----------|----------|------|
| **Next.js** | Framework web moderno basado en React con soporte de renderizado del lado del servidor | ![Next.js](https://skillicons.dev/icons?i=nextjs) |
| **Tailwind CSS** | Framework CSS moderno para desarrollo UI rápido con clases utilitarias | ![Tailwind](https://skillicons.dev/icons?i=tailwind) |

### Servicios de Base de Datos y Backend

| Tecnología | Descripción | Icono |
|----------|----------|------|
| **Supabase** | Solución backend-as-a-service de código abierto alternativa a Firebase | ![Supabase](https://skillicons.dev/icons?i=supabase) |

## ¿Por Qué Estas Tecnologías?

- **Rendimiento:** Carga rápida con características SSR e ISR.
- **Gestión de Estilos Simple:** Estructura CSS limpia y manejable gracias a Tailwind.
- **Gestión de Datos:** Gestión de base de datos en tiempo real y soporte de autenticación con Supabase.
- **Potencia API:** Estructura API REST flexible y personalizable con Express.js.

# Pati Tekno

**Pati Tekno** is an innovative platform offering creative digital solutions developed with modern web technologies. It stands out with its user-friendly interface and robust infrastructure. By using open-source, scalable, and modern tools in its projects, it sets an example in the field of web development.

## About

The aim of Pati Tekno is to provide users with quick access to information, present content with a modern design approach, and create a sustainable, developable digital ecosystem thanks to its technical infrastructure. With its well-balanced design and software structure, user experience is always prioritized.

## Technologies Used

The following technologies are actively used in the construction of the **Pati Tekno** project:

### Frontend

| Technology   | Description                                                        | Icon                                                         |
|--------------|--------------------------------------------------------------------|--------------------------------------------------------------|
| **Next.js**  | Modern web framework based on React with server-side rendering     | ![Next.js](https://skillicons.dev/icons?i=nextjs)            |
| **Tailwind CSS** | Modern CSS framework for rapid UI development with utility classes | ![Tailwind](https://skillicons.dev/icons?i=tailwind)         |

### Database & Backend Services

| Technology   | Description                                                        | Icon                                                         |
|--------------|--------------------------------------------------------------------|--------------------------------------------------------------|
| **Supabase** | Open-source backend-as-a-service solution, alternative to Firebase | ![Supabase](https://skillicons.dev/icons?i=supabase)         |

## Why These Technologies?

- **Performance:** Fast loading with SSR and ISR features.
- **Easy Style Management:** Simple and manageable CSS structure with Tailwind.
- **Data Management:** Real-time database management and authentication support with Supabase.
- **API Power:** Flexible and customizable REST API structure with Express.js.

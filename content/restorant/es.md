# Diseño UI para Restaurante

## Sobre el Proyecto

**Diseño UI para Restaurante** es un proyecto de diseño de interfaz de usuario (UI) moderno y fácil de usar, creado para una marca de restaurante ficticia. El objetivo es ofrecer una experiencia centrada en dispositivos móviles, donde los clientes puedan consultar el menú, hacer reservas y realizar pedidos en línea.

Este proyecto busca apoyar la digitalización de los negocios de hostelería y mejorar la experiencia del usuario.

## Proceso de Diseño

Durante el proceso de diseño UI se priorizaron los siguientes principios:

- **Interfaz amigable:** Experiencia simple, clara e intuitiva.
- **Diseño mobile-first:** Todos los diseños fueron realizados de manera responsive para adaptarse a dispositivos móviles.
- **Apariencia estética:** La paleta de colores, la tipografía y los gráficos fueron diseñados para reflejar una atmósfera cálida y acogedora.
- **Estructura modular:** Cada página está basada en componentes reutilizables, lo que facilita su mantenimiento y escalabilidad.

## Páginas Diseñadas

- Página de inicio (pantalla de bienvenida)
- Página de menú (productos filtrables por categoría)
- Página de reservas (selección de fecha y hora)
- Página de pedidos (carrito, pago y confirmación)
- Página de contacto y sobre nosotros

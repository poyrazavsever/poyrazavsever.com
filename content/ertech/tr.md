# Er Technology

**Er Technology**, okulda tanıştığım [Emir Kemal Eraslan](https://www.linkedin.com/in/emir-kemal-eraslan-3075b2271/)'ın teknoloji girişimidir. Çeşitli yazılım projeleri ve teknolojik çözümler sunan bu ekibe modern bir landing page projesi yapmaya çalıştım.

## Hakkında

Er Technology, yenilikçi teknoloji çözümleri sunmayı hedefleyen genç bir girişimdir:

- **Modern Tasarım**: Kullanıcı dostu arayüz tasarımı
- **Responsive Yapı**: Tüm cihazlarda uyumlu görünüm
- **Hızlı Performans**: Optimize edilmiş kod yapısı

## Kurulum ve Kullanım

```bash
# Projeyi klonlayın
git clone https://github.com/poyrazavsever/Cibik-Website.git

# Proje dizinine gidin
cd Cibik-Website

# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# ya da canlı site --> ertechnology.net
```

# Er Technology

**Er Technology** ist ein Tech-Startup, gegründet von meinem Schulfreund [Emir Kemal Eraslan](https://www.linkedin.com/in/emir-kemal-eraslan-3075b2271/). Für dieses Team, das verschiedene Softwareprojekte und technologische Lösungen anbietet, habe ich eine moderne Landing Page entwickelt.

## Über uns

Er Technology ist ein junges Startup mit dem Ziel, innovative Tech-Lösungen bereitzustellen:

- **Modernes Design**: Benutzerfreundliche UI-Gestaltung  
- **Responsive Aufbau**: Kompatibles Layout auf allen Geräten  
- **Hohe Leistung**: Optimierter Code

## Installation und Nutzung

``` bash
# Projekt klonen
git clone https://github.com/poyrazavsever/Cibik-Website.git

# In das Projektverzeichnis wechseln
cd Cibik-Website

# Abhängigkeiten installieren
npm install

# Entwicklungsserver starten
npm run dev

# oder Live-Ansicht --> ertechnology.net
```

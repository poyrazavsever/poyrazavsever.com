# Er Technology

**Er Technology** es una startup tecnológica fundada por mi amigo del colegio [Emir Kemal Eraslan](https://www.linkedin.com/in/emir-kemal-eraslan-3075b2271/). Desarrollé una página de aterrizaje moderna para este equipo, que ofrece varios proyectos de software y soluciones tecnológicas.

## Sobre nosotros

Er Technology es una joven startup que busca ofrecer soluciones tecnológicas innovadoras:

- **Proyectos de software**: Desarrollo de aplicaciones web y móviles  
- **Diseño moderno**: Interfaz amigable para el usuario  
- **Arquitectura responsive**: Diseño compatible en todos los dispositivos  
- **Rendimiento rápido**: Código optimizado

## ⚙️ Instalación y uso

``` bash
# Clonar el proyecto
git clone https://github.com/poyrazavsever/Cibik-Website.git

# Entrar al directorio del proyecto
cd Cibik-Website

# Instalar dependencias
npm install

# Iniciar el servidor de desarrollo
npm run dev

# o ver sitio en vivo --> ertechnology.net
```

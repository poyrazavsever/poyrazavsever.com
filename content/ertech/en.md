## Installation and Usage

``` bash
# Clone the project
git clone https://github.com/poyrazavsever/Cibik-Website.git

# Enter the project directory
cd Cibik-Website

# Install dependencies
npm install

# Start the development server
npm run dev

# or view live site --> ertechnology.net
```
